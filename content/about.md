# About Me

Hi! I'm Eric, and this is my personal website.

## This Site

This site is built with a custom static site generator I created using:

- **Polylith** - A composable architecture for Clojure
- **Replicant** - A lightweight rendering library
- **Nix** - For reproducible development environments

The entire site generator is structured as reusable Polylith components:

- `markdown-parser` - Parses markdown with frontmatter
- `html-renderer` - Converts markdown to HTML
- `template` - Provides layout functions
- `file-utils` - Handles file operations
- `site-generator` - Orchestrates the build process
